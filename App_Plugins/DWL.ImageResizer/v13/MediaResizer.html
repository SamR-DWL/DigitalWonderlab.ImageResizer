Digital Wonderlab Image Resizer

Smaller images load faster. Use this plugin to easily reduce the size of images that have been uploaded at a larger width than you need to a new maximum width of your choice. Then choose a compression level to further reduce the file size.

Note: It is always possible that further compression has already been applied to your images using alternative sources that may be better for your images. Where the file size increases in the process we will leave the previous image as it is.

1. Max Width

Images exceeding this width will be resized while preserving their aspect ratio. Typically, 2400px suffices, but feel free to adjust as needed.

A higher level of compression will result in a lower file size, but with a greater reduction in image quality.

  • None: No extra compression added.
  • Minimum: Minor compression added resulting in only modest file size savings. Quality reduction should be visually imperceptible.
  • Medium (recommended): Mid-level compression added resulting in decent file size savings. Quality reduction should be barely noticeable visually.
  • Maximum: A higher level of compression added resulting in the lowest file size. Visual quality likely to be affected.

These settings may apply less compression than was originally used on the image, so even though the dimensions are smaller, the re-encoded file can end up larger in size.
